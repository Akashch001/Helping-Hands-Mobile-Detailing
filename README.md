# Helping Hands Mobile Detailing 🚗✨

Official client website for **Helping Hands Mobile Detailing**, Dallas, TX. Built with Next.js 16, TypeScript, Tailwind CSS v4, and GSAP.

---

## 🌟 Overview

A luxury light automotive editorial web application designed for high conversion, owner authenticity, and presentation readiness.

### Key Sections & Features
1. **Responsive Header & Navigation**: Transparent 3D metallic logo, quick-dial phone CTA, and accessible mobile drawer with keyboard focus trap and Escape handler.
2. **Cinematic Hero**: Clean background photography with Dodge Challenger SRT, Archivo Black headline, dual CTAs, and trust highlights.
3. **Meet Chris**: Editorial bio of the owner/operator with 5:6 portrait, authentic handwriting script overlay, and freestanding verified experience metrics.
4. **Detailing Services**: 4-card responsive grid featuring high-resolution WebP photography (Exterior, Interior, Engine Bay, Paint Correction).
5. **Interactive Before & After Slider**: Real-time comparison slider showcasing authentic before-and-after paint restoration on dark clearcoat.
6. **Packages & Pricing**: Clean typography-led pricing tiers for Ultimate Hand Wash Detail ($215), Show Car Detail ($430), and custom quotes.
7. **Verified Customer Reviews**: Authentic 5.0-star customer testimonials with Google review verification indicators.
8. **Interactive Quote Request**: Vehicle detail selector and estimate inquiry form with direct phone and email contact info.
9. **Footer**: Brand summary, operating hours, quick links, and service territory.

---

## 🛠️ Technology Stack

- **Framework**: Next.js 16.4.0 (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 with custom `@theme` tokens
- **Animations**: GSAP & ScrollTrigger with `prefers-reduced-motion` compliance
- **Typography**:
  - *Archivo Black* — Hero headlines & numbers
  - *DM Serif Display* — Editorial headings
  - *Manrope* — Body, navigation, forms, buttons
  - *Caveat* — Authentic cursive van script

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (Node.js 20+ recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Akashch001/Helping-Hands-Mobile-Detailing.git

# Enter the project directory
cd Helping-Hands-Mobile-Detailing

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
npm run start
```
